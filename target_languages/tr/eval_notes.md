# 土耳其语（TR）语言级评估关注点

> 仅记录语言学与地区格式层面的通用关注点。项目术语、语气、标点和产品格式以项目 SG、确认规则及实时要求为准。

## 字母与大小写

- 土耳其语使用拉丁字母，须正确处理 `ç/Ç`、`ğ/Ğ`、`ı/I`、`i/İ`、`ö/Ö`、`ş/Ş`、`ü/Ü`。
- 大小写转换具有 locale 依赖：`i ↔ İ`，`ı ↔ I`。英语式大小写转换可能生成错误字符，尤其影响全大写 UI、搜索和一致性比较。
- `q`、`w`、`x` 不属于土耳其语本族字母，但可合法出现在品牌、代码、缩写和外来专名中，不得机械报错。

## 形态与句法

- 土耳其语为黏着语，重点核对元音和谐、格、所有格、人称、复数、时态、语气及辅音交替。
- 英语介词、助动词和代词结构常需改写为土耳其语后缀或从句；不得按英语词序逐词对应。
- 数词后的普通名词通常不加复数后缀，如数量、兵种、资源、回合和等级表达需重点检查。
- 土耳其语没有语法性别，第三人称代词 `o` 不区分性别；同时仍须保留源文明确的角色身份事实。
- `sen/siz`、命令式与礼貌程度会随受众、关系和文本功能变化；缺少上下文时不得凭英语 `you` 猜测。

## 专名、缩写与变量

- 专名、缩写和数字接后缀时，撇号及后缀形式取决于类别与读音；机构名称、派生后缀和复数等存在例外，需按 TDK 规则及项目 TB 判断。
- 动态变量或占位符的实际读音未知时，固定后缀可能破坏元音和谐。应使用产品支持的后缀变量、缓冲方案或不依赖读音的改写。
- 外来人物名、地名与品牌名优先遵循项目 TB 或官方土耳其语用法；没有权威译名时作为候选处理，不自行声明唯一音译。

## 数字与格式

- 土耳其地区常用十进制逗号和千位点，但游戏可能采用跨地区统一格式；必须先查项目规范和实际产品行为。
- 日期、时间、货币、百分比与单位的顺序及空格需按土耳其地区习惯和产品格式共同判断。
- 数字接序数或格后缀时需核对读音驱动的后缀及撇号，不只比较表面字符。

## UI 与技术文本

- 土耳其语后缀结构可能增加字符串长度；真实组件限制优先于字符数估算。
- 变量、标签、换行和数字必须完整保留；可调整位置以符合土耳其语语序，但不得拆坏标记。
- 自动分词、搜索和大小写无关比较必须采用 Turkish locale，避免 `I/i` 错配。
