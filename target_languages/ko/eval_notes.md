# 韩语审校说明

## 通用检查

- 检查助词、主谓搭配、时态、被动/使动、连接语尾、分写和复合动词拼写。
- 避免逐字照搬中文语序；重点检查名词堆叠、重复主语、僵硬连接和不自然书面腔。
- 标点、数字、变量、标签和换行按项目规则处理；本文件不覆盖项目 SG 或 confirmed rules。

## 语域与人物口吻

- `-요/-습니다`、半语、命令、称谓和人称代词必须依据上游已验证的说话人、受话人、关系、场景及文本类型判断。
- 只有说话人而没有受话人/关系时，不能据此确定敬语等级；资料不足应标记需确认，不猜测人物关系。
- UI、系统提示、教程、叙述和角色对话是不同文本功能，不得用同一套句尾机械处理。
- 原文含冲突、轻蔑、讽刺、亲密或强制语气时，韩语必须保留对应力度；不要无依据统一软化为礼貌体。

## 确定性 register provider 的边界

- provider 只评估 profile 已声明且已确认的 register rule；没有规则或上下文不全时返回 inconclusive。
- provider 的 mismatch 是结构化证据，仍由审校模块结合原文语义判断；复杂嵌套引号、混合句尾、标签干扰或无法可靠识别的句子不得自动判错。
- 项目人物设定和关系规则应存为结构化资产，由当前句段的稳定 key 映射；不要从人物姓名或台词内容临时猜测。
