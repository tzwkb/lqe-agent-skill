# LQE 上下文管线测试用例文档

- 文档版本：2.0
- 日期：2026-08-15
- 干净基线：`336b9c0f6821ee7edd532eeec7f20309c37b6f6a`
- 代码根目录：当前 clean checkout 或 devkit 解包后的顶层目录
- 测试对象：Profile v2、上下文输入与解析、Checker、Suggestion、评分报告、运行时兼容及分发包
- 数据边界：所有示例均为合成数据；本文不包含客户文本、人工参考答案或私有剧情

## 1. 测试目标

验证以下能力在不同 profile 和输入格式下形成完整、可追溯、默认拒绝不安全状态的闭环：

1. 项目资料通过 profile、asset 和 capability 合同显式启用。
2. 表格、旧 `.xls` 和 SDLXLIFF 输入保持字段、坐标、身份及来源摘要。
3. 缺失、冲突或漂移的上下文不会由模型补猜。
4. Checker 与 Suggestion 使用绑定到当前 generation 的同一证据基础。
5. 术语未解决结论、语气不确定性和语言约束冲突会阻止不安全建议发布。
6. 评分、报告、导出和历史任务兼容入口遵守运行时合同。
7. 六个 profile 均完成 shadow/off；其中五个声明了正式上下文的 profile 额外完成临时 enforce canary。
8. 分发包只包含允许运行资产，不夹带开发仓、任务产物或私有回归数据。

## 2. 分支逻辑测试假设

以下假设必须在执行分支测试前确认；若产品合同变化，应先更新假设和测试，再修改期望结果。

| 编号 | 分支 | 测试假设 |
|---|---|---|
| A01 | Profile 版本 | `profile_contract_version: 2` 才启用正式 asset/capability/context 合同；旧 profile 规范化为 `off`，不得获得隐式上下文能力。 |
| A02 | Context 模式 | `off` 不启用可选上下文；`shadow` 只写审计信息；`enforce` 才能影响正式 module view、packet、去重和建议。 |
| A03 | 术语模式 | 标准模式必须具有明确的确认状态；`--no-terminology` 关闭术语、专名和术语审计，但保留准确性、语法、自然度及非术语预检。 |
| A04 | 输入格式 | `.csv/.tsv/.xlsx/.xlsm/.xls` 走 tabular；带 SDL namespace 的 XLIFF 1.2/SDLXLIFF 1.2 走 SDL；XLIFF 2.0、边界歧义和不安全 XML 失败。XLSM 当前没有独立 unittest fixture，发包前必须执行 TC-IN-001 手工 smoke。 |
| A05 | Source 版本 | 业务 key 优先于生成身份；目标绑定的源文摘要漂移时阻断，缺摘要只给未验证警告，不得伪称已验证。 |
| A06 | Pivot | authoritative pivot 不一致会阻断；diagnostic pivot 只告警；重复键或不完整 join 整批失败。 |
| A07 | Alias | canonical ID 精确命中优先；唯一别名可解析；未知别名记为 incomplete；歧义别名记为 conflict，二者都不得选取人物事实。 |
| A08 | 人工补充 | sidecar 只有 `verified`、来源获授权、key 与源摘要匹配且字段已声明时才可应用；失败不得留下半套 job。 |
| A09 | 应用顺序 | 固定为项目 canonical override → 当次 verified sidecar → 语言/语域规则；规则只使用本轮最终绑定的场景和关系事实。 |
| A10 | 相邻句 | scene/group 边界独立生效；strict 模式缺边界时不跨场景回退；受保护或 blocked 邻句不进入正式上下文。 |
| A11 | 去重 | 只有参与模块判断的等价字段影响去重；speaker 等语义字段不同不得合并，业务 key 和 provenance 本身不拆分等价内容。 |
| A12 | 输入计量 | 每个 Checker worker 最多 4 个 packet、25,000 source+target 字符；完整 UTF-8 输入只计量、不设 byte hard cap。主 Agent每轮按 batch plan、cost report 和 manifest 自行判断，所有资料保持完整且不得截断。 |
| A13 | Checker 发布 | 正式发布要求完整 reviewed IDs、当前 packet/manifest/evidence 摘要和唯一真实 worker receipt；旧 generation 或伪造收据失败。 |
| A14 | 术语授权 | 只有当前句精确证据和唯一已确认候选才允许安全术语 edit；近似词、多义词或未解决审查结论不能授权后续改写。 |
| A15 | Suggestion 语义 | 源文是语义唯一依据；原译只用于变量、标签、换行、受保护文本和已验证局部修改。 |
| A16 | Suggestion 语气 | 正式候选的 `tone_decision.uncertainties` 必须为空；未知信息若会改变措辞则 abstain，若可用中性忠实措辞规避则记录 evidence 后继续。 |
| A17 | 约束 | 已确认约束 mismatch 必须硬拒绝；match 仍进入独立 verifier；inconclusive 不得走确定性接收。 |
| A18 | 独立复核 | Suggestion generation、verifier 与 Checker 的 worker/run 身份不得复用；verifier 只能接受、拒绝或要求人工，不能改候选文本。 |
| A19 | 运行时兼容 | 当前 job 必须是 runtime v2；历史 job 只读，续跑必须 `reread` 到新目录，旧任务不得原地派生产物。 |
| A20 | 包边界 | 本次交付是 internal devkit：包含运行代码、schema、受控 profile、自动化测试和 `docs/`；两份交接文档同时复制到 ZIP 旁。不得把 devkit 误标为公开 runtime-only 包。 |

## 3. 测试层级与环境

| 层级 | 目的 | 环境 | 通过标准 |
|---|---|---|---|
| L0 Schema/纯函数 | JSON 合同、解析器、排序和摘要 | Python，离线，临时目录 | 所有合法样例通过；未知字段、版本、摘要和结构篡改失败 |
| L1 CLI/事务 | `read`、`split`、`prepare`、`publish` 等命令边界 | Python + `openpyxl/xlrd/jsonschema/regex/python-docx`；包名 `python-docx` 的导入名是 `docx` | 成功时原子发布；失败时无半套正式产物 |
| L2 管线 E2E | Checker → merge → Suggestion → verifier → final → report/export | 临时 job；全部输入为合成数据 | generation、摘要、收据和证据链完整；错误状态 fail closed |
| L3 Profile canary | 六个真实 profile 的 off/shadow 兼容及适用 profile 的 enforce canary | 允许访问内部 overlay 的受控环境 | 6 个 shadow/off 全部通过，5 个 enforce canary 通过，coverage `unmapped=0` |
| L4 Package | ZIP 内容、安全、解包运行 | 新临时目录，不能借用开发仓文件 | 内容白名单通过、无链接/穿越/缓存/任务数据，解包后原生测试及 profile canary 通过 |

当前版本断言固定如下：job runtime contract 为 2；Checker review packet 为 v3；报告 contract 为 v6；Suggestion generation packet/draft 为 v5；正式参考建议为 v5。Candidate、Suggestion review packet/draft/artifact 当前为 v1。版本变化必须先更新 schema、实现和本文对应测试，不能只放宽测试。

### 3.3 合成数据规则

- 业务 key 使用 `synthetic_001` 等无业务含义值。
- 实体使用 `entity.synthetic.speaker`、`entity.synthetic.addressee`。
- 场景、分组和语域使用 `scene.synthetic`、`group.synthetic`、`register.synthetic`。
- 原文和译文使用合成测试句，不复用任何客户文本、历史反馈文本或人工参考答案。
- Suggestion 预期只验证结构和性质，例如“保留命令 speech act”“不得新增对象”，不保存可与客户数据对应的目标译文。
- 每个负例在独立临时目录运行，避免前一用例生成物影响后一用例。

archive = pathlib.Path(sys.argv[1])
denylist_path = pathlib.Path(sys.argv[2])
allowlist_path = pathlib.Path(sys.argv[3])
deny_terms = [line.strip() for line in denylist_path.read_text(encoding="utf-8").splitlines() if line.strip()]
approved = {}
for line_number, raw in enumerate(allowlist_path.read_text(encoding="utf-8").splitlines(), 1):
    line = raw.strip()
    if not line or line.startswith("#"):
        continue
    match = re.fullmatch(r"([0-9a-fA-F]{64})  (.+)", line)
    expected, rel = (match.group(1).lower(), match.group(2)) if match else (None, line)
    candidate = pathlib.PurePosixPath(rel)
    assert "\\" not in rel and not candidate.is_absolute() and ".." not in candidate.parts
    assert candidate.as_posix() == rel and rel != "SHA256SUMS" and rel not in approved, f"bad allowlist line {line_number}"
    approved[rel] = expected
assert approved, "empty approved allowlist"
forbidden_parts = {
    ".git", "__pycache__", ".pytest_cache", ".mypy_cache", ".ruff_cache",
    ".tox", ".cache", "cache", "caches", "jobs", "input", "inputs", "output", "outputs",

windows_home = re.compile(r"[A-Za-z]:[\\/]+Users[\\/]", re.IGNORECASE)

def scan_text(label, payload):

    assert not any(marker in text for marker in machine_markers), f"machine path: {label}"
    assert not windows_home.search(text), f"machine path: {label}"
    assert not any(term in text for term in deny_terms), f"sensitive phrase: {label}"

    assert infos, "empty archive"
    names = [i.filename for i in infos]

    folded = [unicodedata.normalize("NFC", name).casefold() for name in names]
    assert len(folded) == len(set(folded)), "NFC/casefold path collision"
    roots = {pathlib.PurePosixPath(n).parts[0] for n in names if n}
    assert len(roots) == 1, f"multiple top-level roots: {roots}"

        assert re.fullmatch(r"[0-9a-f]{64}", digest) and rel not in declared

        assert not re.match(r"^[A-Za-z]:", info.filename), info.filename

        assert not info.flag_bits & 0x1, f"encrypted member: {info.filename}"
        mode = (info.external_attr >> 16) & 0o170000
        assert mode != stat.S_IFLNK, f"symlink: {info.filename}"
        lowered = info.filename.lower()
        assert not lowered.endswith(backup_suffixes), info.filename
        if len(path.parts) == 1 and info.is_dir():
            continue

            assert any(item.startswith(rel.rstrip("/") + "/") for item in approved), f"unapproved directory: {rel}"
            continue

        if rel != "SHA256SUMS":

                assert not any("customXml" in name or "absPath" in name for name in office_names)
                content_types = office.read("[Content_Types].xml")
