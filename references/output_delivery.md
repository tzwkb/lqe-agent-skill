# LQE Output Delivery Contract

The customer workbook at `scorecard_profiles/lqe_2026/template.xlsx` is a
reference asset. It documents the historical customer layout and supports
comparison or a future template-fill exporter. The current native report is
generated by `scripts/lqe_io.py write` and `lqe_io._build_xlsx`; the reference
workbook is not an input to that writer.

The native report has four sheets:

- `说明·导读`
- `LQA Scorecard`
- `LQE Results`
- `_LQE_CONTRACT` (veryHidden)

The last sheet binds the visible workbook to the current `state.json` and
`errors.json` under report contract v7. Its `delivery` object records the writer, output mode, reference
template status, job id, creation time, and scorecard profile. A workbook
without that binding is not an LQE delivery, even if its columns or numbers
look plausible.

The finalization script runs `verify-output` after every native `write`. The
verification must pass before the report is delivered. Copying, renaming, or
relabeling an existing workbook cannot replace `write`; if the native pipeline
fails, the job remains incomplete and the failure must be reported.

Each write attempt also updates `report_delivery.json` before writing. A
failed attempt leaves the receipt in `writing` status, which invalidates any
previous report. A successful attempt records the report hash and the current
state/results digests; `verify-output` checks all of them.
